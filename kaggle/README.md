# Kaggle LLM server

**Use `serve_all.ipynb` for real mode.** It runs the LLM (port 8000) and the
BGE embedding service (`embed_server.py`, port 8001), opens one tunnel per
port, prints only the public URLs plus the `.env` lines, records provenance in
`/kaggle/working/provenance.json`, and keeps a heartbeat. It is generated by
`python kaggle/build_serve_all.py`, which inlines `embed_server.py` so the
notebook matches the tested file. Status: `IMPLEMENTED_NOT_TESTED` until run on
Kaggle. After setting `.env`, check with `python -m ai_lawyer.tools.check_remote`.

`serve_llm.ipynb` (LLM only) starts an OpenAI-compatible vLLM server for
**Llama 3.1 8B Instruct** on a Kaggle GPU and exposes it through a cloudflared
quick tunnel. The app talks to it through the existing `openai_compatible`
provider; there is no new adapter.

## What Mri must do

1. Kaggle notebook settings: GPU on, Internet on (phone-verified account).
2. Choose **one** way to get the gated Llama weights:
   - **Hugging Face:** accept Meta's license with your account, revoke the old
     exposed token, create a new read-only token, and store it as the Kaggle
     Secret `HF_TOKEN`.
   - **Kaggle Models:** attach the Llama model to the notebook after accepting
     its license there, then set `MODEL_SOURCE = "kaggle_model"` and
     `KAGGLE_MODEL_PATH` in Cell 1.
3. Add Kaggle Secret `API_KEY`: any random string. Put the same value in the
   app's `.env` as `LLM_API_KEY`. Never commit it.
4. Run the cells in order. Cell 6 waits up to 10 minutes for a cold start.
5. Copy the printed `LLM_BASE_URL` into `.env` on the app machine. The URL
   changes every session; never hardcode it.

## Memory choices

- **T4 x2:** fp16, `--tensor-parallel-size 2`, `--dtype half`,
  `--max-model-len 8192`.
- **T4 x1:** a 4-bit AWQ build, `--max-model-len 8192`. The notebook refuses to
  start fp16 8B on one 16 GB GPU and tells you why.
- If the model fails to load twice, stop and report. The fallback is a smaller
  ungated instruct model; it is not substituted silently.

## Failure messages

- `401`/`403` during download: *license not accepted or token wrong* — fix the
  license/token, do not retry blindly.
- Tunnel URL missing: read `/kaggle/working/tunnel.log`.
- App cannot reach the server: the Kaggle session ended or the URL changed;
  update `LLM_BASE_URL`. There is no silent fallback to the fake model in real
  mode.

## Honesty about the prototype link

A Kaggle session is temporary. The tunnel dies with it, so a reviewer clicking
the link later may find nothing. Keep the notebook and the app tunnel alive for
the review window and say so, or record a demo video as the fallback.
